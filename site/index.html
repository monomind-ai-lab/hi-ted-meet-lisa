Inside every file

Small file. Big machinery.

A file from Ted and Lisa is not a static export — it carries its own navigation, its own languages, and in some shapes, a working prototype.

◐ LANGUAGE

Two languages, one file

English plus Korean or Traditional Chinese in the same file, switched in place. Filenames, commands, and product names are protected — they never get machine-translated into nonsense.

→ NAVIGATION

It presents itself

Scroll-snap slides, arrow keys, touch swipe, and a menu with contents — plus optional PDF and HTML download entries, right in the file's own chrome.

◑ THEMES

Light and dark, measured

Both themes ship in one file with a switch. A design review pass measures contrast in each — and behaviour at phone width — before the file is handed over.

▣ PROTOTYPES

Clickable website mockups

The Sitemap & IA shape doesn't just draw a site structure — it ends in a navigation prototype you can actually click through, at desktop and phone breakpoints.

✎ RESEARCH

Documents that argue

Some shapes are guided research, not slideware: information architecture proposals, system diagrams where colour means something, documents with decision records.

⧉ DIAGRAMS

Diagrams that translate

Diagram-first shapes carry inline SVG — no CDN, works offline, and the labels inside the drawings switch language along with the rest of the file.

The medium

The beauty of one standalone HTML file.

Everything Ted and Lisa make ships the same way — a single .html file. It sounds humble. It's the whole point.

  • It opens anywhere. Double-click it, email it, drop it on any static host. Your audience installs nothing, signs into nothing.
  • It's three deliverables at once. Present it as a talk, print it as a handout, read it as a document — the same file.
  • Nothing in it can rot. No build step, no framework, no dependencies that expire. The file that works today opens the same way in ten years.
  • It's yours to change. Plain, human-readable HTML and CSS — open it in any editor, or hand it back to any agent, and change what you like.
