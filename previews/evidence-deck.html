Scripts in a working deck encode fixes for problems nobody can see any more, so they are copied verbatim rather than tidied. The subject matter is replaced wholesale — not scrubbed, replaced.

The constraint everything else follows from

One file. No build step. No runtime.

1

HTML file per deliverable. It opens from a USB stick, attaches to an email, and survives the folder it was dragged into. Six of the nine templates reach nothing at all beyond Google Fonts.

The exception is deliberate. Two templates load a diagram runtime from a CDN rather than inlining several megabytes of it, and answering delivery: standalone at intake is what inlines it anyway. That is a choice the reader makes, not one the repository makes for them.

If it needs a server to render, it is not finished.

06 / 09

The rules a new template inherits

Five decisions, already made

01One self-contained file, or it is not a deliverableNo build step, no server, no asset folder travelling alongside it
02Export is the browser’s own print dialogue and a self-downloadNever html2canvas, never jsPDF — a bundled exporter would make every file depend on a CDN at read time
03Animation is CSS, or the Web Animations API when it must be scriptedNo animation library; the one that arrived with borrowed work could not be redistributed at all
04One template per shape, never one template with switchesEvery switch multiplies the states somebody has to review, and the shapes share no navigation to begin with
05Third-party work is carried by the lightest mechanism that preserves attributionCopied, submoduled, or derived — and recorded in NOTICE either way
07 / 09

What the intake asks before anything is built

The questions that change the file

  • Which shape? Asked first, because every later question is filtered by the answer. A document is never asked about slide count.
  • Does it need to work offline? delivery: standalone inlines the fonts and any library, at the cost of file size.
  • Which languages? Some shapes write both languages inline and toggle them with CSS; one loads a translator on demand. The mechanism belongs to the template, not to the answer.
  • Keep the credit line? One quiet colophon ships by default, and switching it off deletes exactly one element.
