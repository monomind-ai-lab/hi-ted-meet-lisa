HTML file per deliverable. It opens from a USB stick, attaches to an email, and survives the folder it was dragged into. Six of the eight built here reach nothing at all beyond Google Fonts.결과물 하나당 HTML 파일 하나. USB에서 열리고, 메일에 첨부되며, 어느 폴더에 끌어다 놓아도 살아남습니다. 여기서 만드는 여덟 개 중 여섯 개는 Google Fonts 말고는 아무 데도 접속하지 않습니다.

The exception is deliberate. Two templates load a diagram runtime from a CDN rather than inlining several megabytes of it, and answering delivery: standalone at intake is what inlines it anyway. That is a choice the reader makes, not one the repository makes for them.예외는 의도된 것입니다. 두 템플릿은 수 메가바이트를 파일에 넣는 대신 다이어그램 런타임을 CDN에서 불러옵니다. 인테이크에서 delivery: standalone이라고 답하면 결국 파일 안에 넣습니다. 그것은 저장소가 대신 정해 주는 것이 아니라 읽는 사람이 하는 선택입니다.

The rules a new template inherits새 템플릿이 물려받는 규칙

Six decisions, already made이미 내려진 여섯 가지 결정

01One self-contained file, or it is not a deliverableNo build step, no server, no asset folder travelling alongside it자기 완결적인 파일 하나가 아니면 결과물이 아닙니다빌드 단계도, 서버도, 옆에 딸려 다니는 애셋 폴더도 없습니다
02Every template inherits the house features: a language switch and a menuBoth languages are written into the markup and toggled by CSS, so the file still works offline모든 템플릿은 기본 기능을 물려받습니다: 언어 전환과 메뉴두 언어를 모두 마크업에 적어 두고 CSS로 전환하므로 오프라인에서도 그대로 동작합니다
03Export is the browser’s own print dialogue and a self-downloadNever html2canvas, never jsPDF — a bundled exporter would make every file depend on a CDN at read time내보내기는 브라우저 자체의 인쇄 대화상자와 자기 자신을 저장하는 기능입니다html2canvas도 jsPDF도 쓰지 않습니다 — 번들된 내보내기 도구는 모든 파일을 읽는 순간 CDN에 묶어 버립니다
04Animation is CSS, or the Web Animations API when it must be scriptedNo animation library; the one that arrived with borrowed work could not be redistributed at all애니메이션은 CSS로, 꼭 스크립트가 필요하면 Web Animations API로애니메이션 라이브러리는 쓰지 않습니다. 빌려온 작업에 딸려 온 것은 재배포 자체가 불가능했습니다
05One template per shape, never one template with switchesEvery switch multiplies the states somebody has to review, and the shapes share no navigation to begin with형태마다 템플릿 하나, 스위치가 달린 템플릿 하나가 아닙니다스위치 하나가 누군가 검토해야 할 상태를 곱절로 늘리고, 애초에 형태끼리 내비게이션을 공유하지도 않습니다
06Third-party work is carried by the lightest mechanism that preserves attributionCopied, submoduled, or derived — and recorded in NOTICE either way서드파티 작업은 출처 표기를 지키는 가장 가벼운 방식으로 옮깁니다복사하든, 서브모듈로 걸든, 파생하든 — 어느 쪽이든 NOTICE에 남깁니다

What the intake asks before anything is built무언가를 만들기 전에 인테이크가 묻는 것

The questions that change the file파일을 바꾸는 질문들

  • Which shape? Asked first, because every later question is filtered by the answer. A document is never asked about slide count.어떤 형태인가? 가장 먼저 묻습니다. 이후의 모든 질문이 이 답으로 걸러지기 때문입니다. 문서에게 슬라이드 장수를 묻는 일은 없습니다.
  • Does it need to work offline? delivery: standalone inlines the fonts and any library, at the cost of file size.오프라인에서도 동작해야 하는가? delivery: standalone은 폰트와 라이브러리를 파일 안에 넣습니다. 대가는 용량입니다.
  • Which languages? The slide and document shapes write both languages inline and toggle them with CSS; the talk deck loads a translator on demand. The mechanism belongs to the template, not to the answer.어떤 언어인가? 슬라이드와 문서 형태는 두 언어를 마크업에 함께 적고 CSS로 전환합니다. 발표용 덱만 필요할 때 번역기를 불러옵니다. 방식은 답이 아니라 템플릿에 속합니다.
  • Which menu? A full menu is a hamburger beside the brand mark that lists the slides and jumps to them. The default is on, so a template without one is a template that is lying about its own answers.어떤 메뉴인가? 전체 메뉴는 브랜드 마크 옆의 햄버거로, 슬라이드를 나열하고 그곳으로 이동합니다. 기본값이 켜짐이므로, 메뉴가 없는 템플릿은 자기 답에 대해 거짓말을 하고 있는 템플릿입니다.
